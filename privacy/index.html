中文

NyaMu（若麦）是殷雲清为自己搭建的个人助手程序，只运行在本人自己的电脑上，不对外提供服务，也没有其他用户。

访问哪些数据

经本人授权后，NyaMu 以只读权限（gmail.readonly）读取本人 Gmail 邮箱中的邮件：发件人、主题、时间、正文和附件名称。它不能发送、删除或修改任何邮件。

如何使用

这些数据只用于：在本人的电脑上筛选出重要邮件并提醒本人，以及在本人提问时帮忙查找、概括邮件。

存储与分享

  • 授权凭证和邮件摘要只保存在本人自己的电脑上，不上传到任何服务器。
  • 不出售、不出租、不与任何第三方分享，不用于广告，也不用于训练任何通用 AI 模型。

撤销与删除

本人可以随时在 Google 账号 → 第三方访问 撤销授权；撤销后程序立即无法再读取邮件；本地保存的摘要也可以随时删除。

Google API 有限使用声明

NyaMu 对从 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的“有限使用”要求。

English

NyaMu is a personal assistant built by Yin Yunqing for his own use. It runs only on his own computers, offers no public service and has no other users.

Data accessed

With the owner's consent, NyaMu reads the owner's Gmail messages with read-only access (gmail.readonly): sender, subject, date, body text and attachment names. It cannot send, delete or modify any email.

How it is used

Only to flag important emails to the owner on his own computer, and to look up or summarize emails when he asks.

Storage and sharing

  • Authorization tokens and email summaries are stored only on the owner's own computer and are not uploaded to any server.
  • Data is never sold, rented or shared with any third party, never used for advertising, and never used to train general-purpose AI models.

Revocation and deletion

Access can be revoked at any time in Google Account → Third-party access; after that the program can no longer read email, and the locally stored summaries can be deleted at any time.

Google API Limited Use

NyaMu's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

日本語

NyaMu は殷雲清が自分専用に作った個人アシスタントです。本人のコンピュータ上でのみ動作し、一般向けのサービスは提供しておらず、他の利用者はいません。

アクセスするデータ

本人の同意のもと、本人の Gmail のメール（差出人・件名・日時・本文・添付ファイル名）を読み取り専用（gmail.readonly）で読み取ります。メールの送信・削除・変更はできません。

利用目的

本人のコンピュータ上で重要なメールを知らせること、本人の求めに応じてメールを検索・要約することのみに使います。

保存と共有

  • 認証情報とメールの要約は本人のコンピュータにのみ保存し、サーバーには送信しません。
  • 第三者への販売・貸与・共有、広告への利用、汎用 AI モデルの学習への利用は一切しません。

取り消しと削除

Google アカウント → サードパーティによるアクセス からいつでもアクセスを取り消せます。取り消し後はメールを読み取れなくなります。ローカルに保存した要約もいつでも削除できます。

Google API の限定的使用

NyaMu による Google API から受け取った情報の使用および転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。
